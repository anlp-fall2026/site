{% comment %} Upcoming-deadlines banner. Sources the same events the schedule page shows: every assignment's due_event plus any exam in the lectures collection. All deadlines are rendered into the page with a data-ts epoch, and the script below picks the next `data-count` of them against the *visitor's* clock. That is what keeps the banner correct between site builds: on GitHub Pages nothing rebuilds until the next push, so a build-time-only choice would go stale. Liquid still marks a sensible default so the banner is right without JS. {% endcomment %} {% assign deadline_count = 2 %} {% assign all_dues = "" | split: "" %} {% for assignment in site.assignments %} {% if assignment.due_event %} {% if assignment.due_event[0] %} {% assign all_dues = all_dues | concat: assignment.due_event %} {% else %} {% assign all_dues = all_dues | push: assignment.due_event %} {% endif %} {% endif %} {% endfor %} {% assign exams = site.lectures | where: 'type', 'exam' %} {% assign deadlines = all_dues | concat: exams | sort: 'date' %} {% assign now_ts = site.time | date: '%s' | plus: 0 %} {% assign upcoming_total = 0 %} {% for d in deadlines %} {% if d.time %}{% assign ts = d.date | date: '%s' | plus: 0 %}{% else %}{% assign ts = d.date | date: '%s' | plus: 86399 %}{% endif %} {% if ts >= now_ts %}{% assign upcoming_total = upcoming_total | plus: 1 %}{% endif %} {% endfor %} {% if upcoming_total > 0 %}
