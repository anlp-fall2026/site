Build a retrieval-augmented generation system end to end: compile your own knowledge
resource about Pittsburgh and CMU, chunk and index it, implement dense, sparse, and
hybrid retrieval yourself, and generate answers to factual questions. There is no starter
code and you collect the data yourself, so start early. Individual assignment, 100 points.

Everything is also in the [hw2-public repo](https://github.com/anlp-fall2026/hw2-public),
including the LaTeX sources. Use `public_evaluation_data.json` — 157 questions with
reference answers — as your development set and run your ablations against it.

A public leaderboard will follow. We will post the link and its queries on Piazza; those
queries differ from the public evaluation data, their reference answers will not be
released, and leaderboard scores do not count toward your grade. Your final system is
evaluated on a private test set released Thursday, October 22, one day before the deadline.

Submit all deliverables on Canvas as a single zip, named for your lowercase Andrew ID:

```
ANDREWID/
├── report.pdf
├── github.txt
├── data/
│   └── train (optional)/
│       ├── questions.txt
│       └── reference_answers.json
├── system_outputs/
│   ├── system_output_1.json
│   ├── system_output_2.json (optional)
│   └── system_output_3.json (optional)
└── README.md
```

`github.txt` holds a link to a private GitHub repo with your code, shared with the TAs.
The report has a 7-page limit and must use the ACL template.

Late submissions cost 5% per day (see the [syllabus](/syllabus)). If you plan to submit
late, post on Piazza first — we release a different test set for each late day.
